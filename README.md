# タスク管理 & Discord 通知アプリ

FlaskとAPSchedulerを組み合わせた、タスクの登録・自動通知を行うWebアプリケーションです。
指定したスケジュールに合わせて、Discordへ自動でリマインド通知を行います。

# 権利・ライセンスについて

本リポジトリはテンプレートを利用して作成されています。

- **テンプレート由来のコード・素材:** 元の制作者および各ライセンスに帰属します。
- **本リポジトリ独自の追加・変更部分:** 製作者(@kondokeito)に著作権が帰属します。

### 利用上の注意
製作者に著作権が帰属する部分について、著作権法上の「私的使用のための複製」等、権利制限規定の範囲を超えた無断での転載、二次配布、商用利用を固く禁じます。
